## 为什么要有个自己的博客

刷别人的博客刷了很多年，一直想着"我也该有一个"。真正动手的契机很普通：某天发现自己搜索解决过的问题，过两个月又忘干净了。

与其反复踩同一个坑，不如把过程写下来。既方便自己回头查，万一也帮到别人，那就更好了。

## 这个博客是怎么搭的

技术上用的是 [Astro](https://astro.build/) 加 [Fuwari](https://github.com/saicaca/fuwari) 主题：

- **Astro** 默认输出纯静态 HTML，几乎没有 JavaScript，所以加载非常快
- **Fuwari** 提供了毛玻璃卡片、深色模式、主题色切换和页面过渡动画
- 文章全部是 Markdown 文件，写完直接提交，不需要数据库，也没有后台

## 之后打算写什么

大概会分三类：

1. **技术笔记**：踩过的坑、用过的工具、读过的好代码
2. **效率方法**：知识管理、工作流、自动化的小技巧
3. **生活随笔**：读书、旅行、一些没什么用但想记下来的念头

> 写博客最难的不是技术，是坚持。先把第一篇发出去，剩下的慢慢来。

## 一段代码示例

顺便验证一下代码块的效果：

```ts
function greet(name: string): string {
  return `你好，${name}！欢迎来到我的博客。`
}

console.log(greet('世界'))
```

就这样，第一篇到此结束。
